دليل تشغيل واستخدام مشروع: منصة مصر الذكية للعمل المناخي
مسابقة: التغيرات المناخية والتكنولوجيا للمرحلة الثانوية
==================================================

1. البرمجيات واللغات البرمجية المستخدمة:
   - HTML5: لبناء هيكل وشاشات التطبيق التفاعلي.
   - CSS3: لتنسيق واجهة المستخدم والألوان وتسهيل التنقل.
   - JavaScript: لبرمجة حاسبة الأثر الكربوني والتفاعلية.

2. كيفية تشغيل المشروع:
   - افتح مجلد المشروع (مشروع_المناخ).
   - اضغط مرتين (Double Click) على ملف (index.html) ليفتح مباشرة عبر أي متصفح إنترنت (Chrome / Edge / Firefox).
   - لا يتطلب المشروع الاتصال بالإنترنت ويعمل أوفلاين بشكل كامل.

3. طريقة الاستخدام:
   - الشاشة الرئيسية: تعرض أهداف البرمجية وعلاقتها باستراتيجية مصر المناخية 2050.
   - حاسبة البصمة الكربونية: ادخل القيم العددية في الخانات المخصصة ثم اضغط "احسب الأثر البيئي" لعرض النتيجة.
   - قسم التكنولوجيا الخضراء: يقدم معلومات تفاعلية عن الحلول التقنية.
   - خروج: اضغط على زر "إغلاق التطبيق" في أسفل الصفحة عند الانتهاء.
